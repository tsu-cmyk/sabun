📖 SABUN 使用説明

1. ファイルの読み込み

  • 「A を開く」「B を開く」ボタン、または Ctrl+A / Ctrl+B
  • 画面へのPDFドラッグ&ドロップ（2ファイル同時ドロップでA/Bに割り当て）

2. 比較モード

  • A [1] / B [2] — 各PDFを単独表示
  • ハイライト [3] — B側のみの要素(追加)を橙、A側のみの要素(削除)を水色で強調
  • あおり [4] — AとBをタイマーで交互表示
  • 絶対値差 [5] — 変更量をグレースケール表示
  • スプリット [6] — 左A / 右B の分割表示。ドラッグで境界を移動
  • 領域枠 — 差分領域を黄色枠+番号で表示(A/B以外の全モード共通、「領域枠」チェックでON/OFF)。N/Pでジャンプ
  • テキスト差分パネル [7] — タブとは独立したサイドパネル。差分箇所一覧(変更/追加/削除)のクリックでPDF上の該当箇所へズーム。HTMLレポート保存可
  • 差分ページ一覧パネル [8 / Ctrl+L] — ページ一覧と差分領域一覧の2段構成サイドパネル。各段に前後ジャンプボタン、境界はドラッグで高さ調整可
  • PDF内のコメント注釈の表示は、ハイライト/絶対値差以外のモードで「PDF内の注釈を表示」をONにすると見られます（差分判定には影響しません）

3. 位置合わせとページ対応

  • 自動位置合わせ — オフセット横の「自動」でON。現在ページのA/BのズレをWorkerが自動推定して補正します。もう一度押すとOFFになり元のオフセットへ戻ります
  • ページ番号がズレるPDF同士 — A/Bのサムネイルをそれぞれクリックして見たいページの組み合わせを選べます（ページ送りはそのズレを保ったまま動きます）
  • A/Bサムネイル欄へのドロップ — PDFをA欄/B欄に直接ドロップすると読み込み先を指定できます(再読み込みに便利)

4. 検版レポート

  • ツールバーの「レポート」で全差分ページのハイライト画像・差分領域一覧・テキスト差分を1つのHTMLに出力。開いて「印刷 / PDF保存」ボタンからPDF化できます

5. 差分検出のしくみ

  • レンダリング解像度は固定（画質: 標準2x / 高3x）。ズームしても差分結果は変わりません
  • PDF内のコメント注釈は差分判定・比較ビューから常に除外されます
  • A/B読込後、全ページを自動スキャン（画像＋テキスト）。橙ドット=画像差分 / 青ドット=テキスト差分
  • 「感度」変更後は差分一覧パネルの ⟳ で再スキャン

6. 注釈（Adobe Acrobat互換）

  • 対象の指定 — 注釈バー先頭の「対象」で A / B / A+B を選択。手描き・自動付与・保存すべてに適用されます
  • 記入者 — 注釈の作成者名（デフォルト: ADP）。PDF注釈・XFDFの作成者として記録され、Acrobatのコメント一覧に表示されます
  • ツール: 選択V / 矩形R / 楕円O / 線L / 矢印A（注釈バー表示中のみ・同じキーをもう一度押すと解除）。描画後は自動で選択ツールに戻ります（「維持」ONで連続描画）
  • 複製 — 選択中の注釈を Ctrl/Cmd+C → Ctrl/Cmd+V でコピペ、または Option/Alt+ドラッグでその場複製
  • サイズ変更 — 選択中の注釈は四隅（線・矢印は両端点）のハンドルをドラッグ。テキストは高さに合わせて文字サイズも変わります。矢印キーで1pt移動（Shiftで10pt）
  • スタイル — 線色 / 塗り(なし・色) / 線幅(0.5〜5pt) / 線種(実線・破線・点線)。選択中の注釈にも即適用
  • 注釈中の画面操作 — ツール選択中も Spaceドラッグ / マウス中ボタン / ホイール / Ctrl+ホイール でパン・ズームできます
  • 差分領域を注釈化 — 検出された差分領域の枠サイズで矩形注釈を一括付与（初期値: 塗りなし・赤線・1pt実線）
  • 注釈入りPDF保存 — Acrobatの長方形・楕円・線・矢印・テキストコメントとして実PDFに埋め込み。Acrobatでそのまま選択・編集・削除できます
  • XFDF書き出し — Acrobatの「コメント > 読み込み」で元PDFに注釈として取り込む場合に使用
  • 注釈一覧 — 注釈バーの「一覧」で全ページの注釈をパネル表示。クリックでジャンプ、✕で個別削除

8. 安定動作のための設計

  • 差分計算はWeb Workerで実行され、大きなPDFでも操作がブロックされません
  • レンダリング解像度固定により、ズーム時の再計算が発生しません
  • ページキャッシュは搭載メモリに応じて上限管理（ステータスバーに使用量表示）
  • サムネイルは表示範囲のみ逐次生成し、メモリを節約します
